# Portfolio_Markowitz
Este repositório contém um código em Python para análise de uma carteira de investimentos usando a teoria de portfólios de Markowitz. O código utiliza retornos históricos de ativos, covariância e métricas de risco para otimizar alocações de portfólio. O repositório oferece uma ferramenta prática para diversificação de portfólio e gerenciamento de risco.
